# Contributing

Please open an issue describing a concrete problem or proposal first. Small, reviewable pull requests are welcome. Explain behavior changes and run relevant tests. Do not invent benchmarks or claim autonomous learning.

For voice changes, compare the same German phrases on the same hardware: recognition errors, interrupted sentences, time to first audio, and memory usage. Use only your own or explicitly permitted recordings.

Preserve deliberate memory storage, localhost defaults, and certificate pinning. No silent cloud fallback, execution of model text as commands, or global network/certificate bypasses. Document new external requests.

Never commit conversations, databases, personal documents, pairing codes, keys, or Apple profiles. Original-code contributions are accepted under MIT; incorporated third-party code must retain attribution and license notices.
