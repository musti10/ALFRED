# Roadmap

1. Compare fixed silence thresholds with Silero VAD / Smart Turn for German conversations.
2. Evaluate responses with fixed German questions; prevent fabricated weather and capabilities.
3. Compare Piper Thorsten with a suitable German Qwen3-TTS / MLX-Audio voice, measuring memory, latency, and listening quality.
4. Add opt-in, source-backed web search with visible external requests.
5. Process deliberately selected documents locally with separate storage and deletion controls.
6. Develop a portable iOS certificate strategy without a personal address in the build.
7. Investigate always-available hosting and later on-device iPhone inference.

These are proposals, not implemented capabilities.
